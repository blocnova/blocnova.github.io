BlocNova instruments v3 — MobileNetV3-Small 1.0 224 retrained on photos of surgical
instruments. TensorFlow.js graph model: input 224 x 224 x 3 in [0, 1], output 1 024 floats.

Base model
  MobileNetV3-Small 1.0 224, ImageNet feature vector, TensorFlow.js
  https://www.kaggle.com/models/google/mobilenet-v3  (tfJs / small-100-224-feature-vector / 1)
  Google (Howard et al., "Searching for MobileNetV3", 2019). Apache License 2.0
  https://www.apache.org/licenses/LICENSE-2.0

Changes (17/10/2026, v3)
  Same graph, same input and output. The weights were retrained (fine-tuned) by
  ml/instruments/entrainer.py of the BlocNova repository; the first four layers are
  unchanged. This model is distributed under the Apache License 2.0, like the base model.
